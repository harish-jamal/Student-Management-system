# Student Management System

A Student Management System developed using C Programming and Raylib.

**Live Demo:** https://harish-jamal.github.io/Student-Management-system/

## Features

* Add Student
* Edit Student
* Delete Student
* Search Student

## Technologies Used

* C Programming
* Raylib
* Visual Studio Code
* GCC Compiler

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Compile the C program using GCC and Raylib.
4. Run the generated executable file.
